# npm-package

This repository contains **`@varad123/student-toolkit`**, a production-quality, beginner-friendly JavaScript npm package for college students to calculate attendance, required classes, examination percentage, SGPA, and CGPA.

## Project Structure

- [`student-toolkit/`](./student-toolkit/): The core npm package source code, tests, documentation, and examples.
  - [`src/`](./student-toolkit/src/): Core calculation modules (`attendance.js`, `percentage.js`, `sgpa.js`, `cgpa.js`, `index.js`).
  - [`tests/`](./student-toolkit/tests/): Automated unit test suites (Vitest).
  - [`examples/`](./student-toolkit/examples/): Real-world usage demonstrations.
  - [`package.json`](./student-toolkit/package.json): Package metadata and exports.
  - [`README.md`](./student-toolkit/README.md): Comprehensive package documentation and API guide.

For full documentation, API reference, and usage examples, see the [Student Toolkit README](./student-toolkit/README.md).
